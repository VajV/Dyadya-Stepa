# Фото с ТВИЛа — куда кидать

Сейчас слайдеры карточек заполнены фотографиями отеля со 101hotels. Если какое-то фото
не подходит — скачай нужные с ТВИЛа (https://tvil.ru/city/adler/hotels/602361/) и закинь
в папку соответствующей карточки (jpg/png, любой размер — потом сожмём и подставим):

| Папка | Карточка на сайте |
|---|---|
| 1-dvuhmestny-standard | Двухместный номер Standard |
| 2-trehmestny-standard | Трёхместный номер Standard |
| 3-studiya-standard | Номер-студия Standard |
| 4-apartamenty-1-spalney | Апартаменты с 1 спальней (Хит продаж) |
| 5-lyuks | Люкс (Две комнаты) |
| 6-studiya-deluxe | Номер-студия Deluxe (Maximum) |
| 7-semeyny-lyuks | Семейный люкс (Максимум) |
| 8-byudzhetny-dvuhmestny | Бюджетный двухместный номер |
| 9-byudzhetnye-apartamenty | Бюджетные апартаменты |
| galereya-dop-foto | Доп. фото для всплывающей галереи («Смотреть все фото») |

После того как закинешь — скажи Claude «обнови фото из папок», и он пережмёт их в WebP
и подставит в слайдеры вместо текущих.
